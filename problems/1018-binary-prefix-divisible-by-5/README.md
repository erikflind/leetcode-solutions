# Problem: 1018. Binary Prefix Divisible By 5

**Link:** [https://leetcode.com/problems/binary-prefix-divisible-by-5/](https://leetcode.com/problems/binary-prefix-divisible-by-5/)

**Summary:**  You are given an array `nums` filled with 1's and 0's, where the binary number `x_i` is the subarray `nums[0..i]` (MSB -> LSB). Return an array of booleans where `array[i]` is true if `x_i` is divisible by 5.
