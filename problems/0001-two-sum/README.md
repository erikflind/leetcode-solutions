# Problem: 1. Two Sum

**Link:** [https://leetcode.com/problems/two-sum/](https://leetcode.com/problems/two-sum/)

**Summary:**  Given an array of integers and an integer *target*, return the indices of the two numbers that sum up to *target*.

**Solution Approach:**
- iterative ~ O(n^2) ~ Java
- iterative + HashMap ~ O(n) ~ Java
