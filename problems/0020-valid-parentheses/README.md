# Problem: 20. Valid Parentheses

**Link:** [https://leetcode.com/problems/valid-parentheses/](https://leetcode.com/problems/valid-parentheses/)

**Summary:**  Check if an input String containing `'('`, `')'`, `'{'`, `'}'`, `'['` and `']'` is valid, i.e., every open bracket is closed by the corresponding close bracket of the same type in the correct order.
