# Usage

- `add_solution.py`:
  - creates new problem directory,
  - adds template source files + **problem** README,
  - generates the **main** README.
    - See `--help` for usage details.
- `generate_readme.py`:
  - regenerates the **main** README.md with an up-to-date [Problems table](../#problems).
- `config.py`:
  - filepaths and language configuration (supported languages, file extensions, and comment syntax).
- `templates.py`:
  - String templates for generating READMEs and source-file headers.
