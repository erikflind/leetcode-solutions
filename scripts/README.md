# Scripts

- `add_solution.py`: creates new problem directory, adds template source files and **problem** README, and (re-)generates the **main** README.
  - See `--help` for usage details.
- `generate_readme.py`: regenerates the **main** README.md with an up-to-date *Contents* table.
- `config.py`: probides filepaths and language configuration (supported languages, file extensions, and comment syntax).
- `templates.py`: contains string templates for generating READMEs and source-file headers.
